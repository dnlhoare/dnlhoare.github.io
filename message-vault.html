A SMALL TOOL FOR PRIVATE MESSAGES

Message Vault

Create a one-way SHA-256 fingerprint, or encrypt a message with a shared keyword.

Encrypt a message

Choose a shared keyword, then send the encrypted result to the person who knows it.

Both people need the same keyword. Use a long phrase that you have shared privately.

Hashing and encryption are different

A SHA-256 hash is a one-way fingerprint. It cannot be decrypted. Use encryption when you need to get the original message back.

A shared keyword is symmetric encryption

This tool uses AES-GCM with a key derived from your keyword. Both people use the same secret. This is not public-key encryption: for that, the recipient would publish a public key and keep a separate private key.

What you can trust

Message text and keywords are processed in this browser and are not sent to a server by this tool. Anyone can inspect the page code, but that alone does not prove the site or hosting account cannot be changed. For sensitive use, verify the source and deployment independently, and exchange the keyword through a separate trusted channel. This is not a substitute for a reviewed, audited messaging service.
